# QUANTNEX Development Roadmap

- Phase 01 — Monorepo foundation, platform skeletons, UI prototype and security boundaries.
- Phase 02 — Trading tools MVP: position sizing, local trade journal and bot monitor placeholder (web implementation).
- Phase 03 — Windows desktop MVP: plain Tkinter interface, position-size calculator, local SQLite journal, GitHub Releases update check and automated Windows EXE build artifact.
- Phase 04 — Secure backend/API, authentication, shared data contracts and local-to-server connectivity; Android and Windows feature parity.
- Phase 05 — Market data adapters and watchlists (read-only first).
- Phase 06 — Bot monitoring and controlled bot operations with independent execution service and risk guard.
- Phase 07 — Verified update service, signed manifests, staged rollout, health checks, backup and rollback.
- Phase 08 — AI assistant, market intelligence and advanced analytics.

The current Windows app is a local MVP. It does not connect to brokers, stream live prices, run bots or place orders. Every phase requires testing; no profitability claims are made.
