# QUANTNEX Development Roadmap

- Phase 01 — Monorepo foundation, platform skeletons, UI prototype and security boundaries.
- Phase 02 — Trading tools MVP: position sizing, local trade journal and bot monitor placeholder (web implementation).
- Phase 03 — Secure backend/API, user authentication, data contracts and local-to-server connectivity.
- Phase 04 — Android and Windows clients consume shared APIs; native calculator/journal parity.
- Phase 05 — Market data adapters and watchlists (read-only first).
- Phase 06 — Bot monitoring and controlled bot operations with independent execution service and risk guard.
- Phase 07 — Update services, signed manifests, staged rollout, health checks and rollback.
- Phase 08 — AI assistant, market intelligence and advanced analytics.

Every phase is subject to testing. No profitability claims. Live execution remains disabled until broker-specific safeguards and testing are complete.
