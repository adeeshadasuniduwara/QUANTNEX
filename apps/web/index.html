Telegram bot connection

Use your own private bot and chat.

LOCAL SETUP

Credentials are used for this request only and are not saved by this page.

  1. Open Telegram and search for @BotFather.
  2. Send /newbot, follow the prompts and choose a bot name and unique username.
  3. Copy the new bot token privately. Never post it in GitHub, screenshots or public chats.
  4. Open your new bot and press Start.
  5. For a private chat, send a message to your bot, then obtain your chat ID using a trusted Telegram bot/API tool. For a channel, add your bot as an administrator with permission to post and enter @ChannelUsername.
  6. Start the QUANTNEX local API, enter token and chat ID above, then press Test.

Keep the token private. If it is exposed, revoke it with BotFather and create a new one.
